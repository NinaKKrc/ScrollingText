# ScrollingText – Naloga 4

## Opis naloge
Aplikacija ScrollingText je izdelana v Android Studiu z uporabo Jave in XML. Namen naloge je prikaz daljšega besedila z možnostjo navpičnega drsenja.

## Delovanje aplikacije
- **ScrollView** omogoča navpično drsenje besedila.
- **LinearLayout** razporedi besedilo v dva stolpca.
- **TextView** prikazuje podnaslov v levem stolpcu (100dp) in članek v desnem.
- **strings.xml** vsebuje besedilo aplikacije.
- **Button** ob kliku prikaže Toast sporočilo *Comment submitted!*

## Odgovori na vprašanja

**1. Koliko gradnikov lahko vsebuje ScrollView?**

**b)** En gradnik View ali en gradnik ViewGroup.

**2. Kateri XML atribut v LinearLayoutu uporabite, da se gradniki prikažejo drug ob drugem?**

**a)** `android:orientation="horizontal"`

**3. Kateri XML atribut uporabite za določitev širine LinearLayouta znotraj drsnega pogleda?**

**b)** `android:layout_width="match_parent"`

## Uporabljene tehnologije
- Android Studio
- Java
- XML
